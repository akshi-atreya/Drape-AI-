# Drape — AI Fashion Personal Shopper

A conversational AI stylist MVP: chat with an AI to get complete, budget-aware
outfits built from a mock multi-retailer catalog, remix them conversationally,
try them on, save looks, and track trends.

## Stack

- **Next.js 15 (App Router) + TypeScript + Tailwind v4**
- **Anthropic Claude** (`claude-sonnet-5`) for conversation, intent extraction,
  and styling explanations, via tool use
- **Zustand** for client state (chat thread, style profile, wardrobe, saved looks),
  persisted to `localStorage`
- A deterministic **recommendation/scoring engine** (`src/lib/recommendation-engine.ts`)
  that owns all product selection, budget math, and ranking — the LLM never
  invents or scores products itself, only calls tools and phrases the reply

## Getting started

```bash
npm install
cp .env.local.example .env.local   # then add your ANTHROPIC_API_KEY
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

You need an Anthropic API key (from [console.anthropic.com](https://console.anthropic.com))
in `.env.local` for the chat to work — the app tells you clearly in the UI if
it's missing.

## Architecture notes

- **Product catalog** (`src/data/products.json`, generated by
  `scripts/generate-products.mjs`): ~245 mock products across 7 categories and
  6 "retailers," all sharing the normalized `Product` shape in
  `src/lib/types.ts`. Swap `src/lib/catalog.ts` for a real feed/DB later —
  nothing else needs to change.
- **Recommendation engine** (`src/lib/recommendation-engine.ts`): scores
  products on style/color/occasion/trend/brand fit, assembles complete outfits
  from recipes (separates vs. dress-based), and optimizes to budget by
  swapping the worst price/score item. Also handles conversational remix via
  a small rule-based instruction parser (`parseRemixInstruction`).
- **Chat API** (`src/app/api/chat/route.ts`, `src/lib/chat-tools.ts`): Claude
  is given four tools — `update_style_profile`, `find_outfits`,
  `remix_outfit`, and `respond_to_user` (always called last to end the turn).
  The route loops on tool calls, executing each against the recommendation
  engine, until `respond_to_user` is called. The route is stateless — the
  client sends the full conversation, profile, and current outfits each turn.
- **Virtual try-on** (`src/app/api/tryon/route.ts`, `TryOnModal.tsx`): the UI
  and API seam are built, but there's no real garment-compositing model wired
  up — it shows an honest "style preview" (your photo + the outfit's pieces)
  rather than a fabricated generated image. Swap in a real try-on API in the
  route handler.
- **Fashion news** (`src/lib/news-source.ts`): seeded from `src/data/news.ts`
  for the MVP; swap the function body for a live news/web API call in
  production.
- **Product imagery**: the mock catalog has no real photography, so
  `ProductSwatch` renders a color wash (the product's actual color) with a
  minimal category icon instead of a fake stock photo.

## Project structure

```
src/
  app/            Routes: / (chat), /trends, /wardrobe, /saved, /api/chat, /api/tryon
  components/     UI components
  lib/            Types, recommendation engine, catalog, chat tools, style profile
  data/           Mock products.json, trends.ts, news.ts
  store/          Zustand app store
scripts/          Product catalog generator
```
